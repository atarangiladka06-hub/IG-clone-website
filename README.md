# Instagram Clone Website

This project is a front-end Instagram clone website that I developed as part of my learning journey in web development and Git/GitHub fundamentals.

The main purpose of this project was to understand how a real-world social media interface is structured and to gain practical experience with creating web pages, organizing project files, writing HTML and CSS, and managing source code using Git and GitHub.

## Project Overview

The website is inspired by the basic design and layout of Instagram. It focuses on recreating the visual structure and user interface of a social media platform, including elements such as user profiles, posts, navigation, and other commonly found components.

This project was created primarily for educational purposes and does not aim to reproduce Instagram's complete functionality or backend services.

## What I Learned

While building this project, I gained practical experience with:

* Creating webpages using HTML
* Styling webpages using CSS
* Structuring a front-end project
* Creating reusable and organized UI components
* Understanding basic responsive web design concepts
* Managing project files using Git
* Initializing and configuring a Git repository
